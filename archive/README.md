## Active Production Files in Project Root

The following files remain active in the project root:
- `export_dashboard_data.py`: Exporter generating JSON data contract for the dashboard.
- `make_report_assets.py`: Report asset generator producing tables and figures in `report_assets/`.
- `check_dashboard.py`: Comprehensive integrity and schema verification script for `docs/`.
- `pressure_core.py`: Canonical pressure model statistical core implementation.
- `run_lighthouse.mjs`: Automated Lighthouse performance, accessibility, and best practice audit runner.
- `playwright.config.js`: Configuration for end-to-end and responsive UI tests.
- `README.md`: Primary project documentation and reproduction instructions.
